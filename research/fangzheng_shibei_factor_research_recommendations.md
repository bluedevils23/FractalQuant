# 方正证券“拾贝市场研究笔记”因子研究建议

## 范围与结论

本笔记覆盖 `D:\研报\方正证券-拾贝市场研究笔记` 的 10 份 PDF（2019-02 至 2019-07）。其中最值得进入本项目研究队列的不是新的单一技术指标，而是五组**条件化、可检验、可交易**的信号：

1. 短周期收益的状态依赖反转；
2. 放量上涨的过热/反转（FLY）；
3. ETF 份额流与价格的非线性交互；
4. 特大单-小单资金流分化；
5. 价值-质量、ESG 争议和市场状态过滤。

不建议直接把报告中的历史结论当作当前 alpha。报告样本主要截止 2018/2019 年，且多为日频或月频；所有候选因子均应在当前样本中按时间滚动、含交易成本、按可交易性过滤后重新验证。

## 一、价格与量价因子

### 1. 多尺度动量/反转（研究笔记 1，第 3-5 页）

原文对过去 `N` 日累计涨跌幅与未来 `H` 日累计收益计算 IC，遍历 `N,H=1..250`；结论是 A 股 `1/1` 日为动量（报告期均值 IC 约 5.27%），5 日和约 20 日表现为较强反转，并且预测期与回望期大致匹配。可写为：

```text
r_t(N) = close_t / close_(t-N) - 1
f_mom(N) = r_t(N)
f_rev(N) = -r_t(N)
label(H) = close_(t+H) / close_t - 1
IC(N,H) = corr_cs(f_t(N), label_t(H))
```

建议实现：

* 日频股票：优先研究 `N=1, 5, 20`，以 `H=N` 为主，并测试 `H=1,5,10,20`；对 5/20 日使用反转方向。
* ETF 1min：不要机械把日频 5/20 映射成 5/20 分钟。先做 `1,5,15,30,60` 分钟的二维 `N-H` IC 热图，按同日标签、午休断开、日末截断。
* 建立滚动 regime 选择器：只在过去 60 个交易日对应方向的 rank-IC 显著为正时启用；避免固定地长期持有同一动量/反转符号。
* 交易过滤：停牌、涨跌停、开盘/收盘不可成交、低成交额标的必须在构造因子前排除，报告 5 的反例证明这一点会改变结论。

### 2. 量价齐飞 FLY（研究笔记 5，第 1-4 页）

原文明确给出：

```text
FLY_t = corr(Price, Turn)
```

它意在捕捉“放量上涨”，而非泛化的量价相关。原文在 2011-2017 年、换手与收益双排序中发现高换手+高涨幅组为显著负 alpha；修正月末涨幅超过 9.5% 的不可买入样本后，所谓“低换手动量”消失，但高换手高收益的反转仍在。

建议实施为两个互补版本：

```text
FLY_corr(L) = corr(r_(t-L+1:t), turnover_(t-L+1:t))
FLY_hot(L)  = zscore(r_t(L)) * zscore(turnover_t(L))
```

其中 `turnover=volume/free_float_shares`；ETF 若无可靠流通股本，采用 `log(volume)` 或 `amount/NAV` 代理，并单独评估。交易方向为低 `FLY` 做多、高 `FLY` 做空/减仓；不能将其直接等同于传统 `price_volume_decoupling`，因为后者衡量的是脱钩，FLY 衡量的是同向过热。

### 3. 牛市尾部风险状态（研究笔记 6，第 1-2 页）

报告发现牛市阶段日收益均值和中位数上升，但方差及左尾风险也上升，“牛市多长阴”。这不是单股 alpha，更适合作为仓位风险门控：

```text
left_tail_share(W,a) = mean(r_index < -a, trailing W)
tail_asymmetry(W) = q05(r_index,W) + q95(r_index,W)
regime = {trend, realized_vol, left_tail_share, tail_asymmetry}
```

当趋势为正但 `left_tail_share` 或短窗下行半方差抬升时，下调高 beta、动量及高换手暴露；反转模型保留但缩短持有期。该因子不能用当日收盘后的全日统计预测当日，必须在下一交易时点使用。

## 二、资金流与 ETF 因子

### 4. ETF 份额流-价格交互（研究笔记 4，第 1-4 页）

报告显示创业板 ETF、50ETF 在 2015 与 2019 牛市初期均出现份额下降；因此“净申购为多、净赎回为空”的单向解释不成立。候选定义：

```text
share_flow_k = (shares_t - shares_(t-k)) / shares_(t-k)
price_trend_k = close_t / close_(t-k) - 1
etf_flow_interaction = zscore(share_flow_k) * zscore(price_trend_k)
```

研究设计应检验四象限而非单变量：上涨-申购、上涨-赎回、下跌-申购、下跌-赎回。预测目标应至少包含未来 1/5/20 日收益与未来波动；并按宽基、行业、跨境、商品、债券 ETF 分组，避免把申赎机制不同的产品混合。若仅有 1min OHLCV 而没有份额历史，不能伪造该因子。

### 5. 成交规模分层资金流（研究笔记 9，第 3-6 页）

报告强调“大/小单”是**按单笔成交金额划分**，不能直接解释为机构/散户。Wind 终端口径包括小单、 中单、大单、特大单；并发现牛市中小单净流入、特大单净流出会同时增强。报告也指出 2016-2018 的历史数据存在不守恒问题，2019-01-11 后才修正。

建议以本项目逐笔成交自行构造，避免依赖供应商标签：

```text
notional_i = price_i * qty_i
signed_notional_i = sign_i * notional_i
flow_b,t(W) = sum(signed_notional_i for i in bucket b, i in W)
flow_divergence(W) = (flow_small(W) - flow_large(W)) / total_notional(W)
flow_large_z(W) = zscore(flow_large(W) / total_notional(W))
```

分桶应采用**当日或滚动横截面分位数**，而非固定金额阈值，才能跨股票和 ETF 比较；方向 `sign_i` 必须用委托/逐笔方向或 Lee-Ready 类规则估计。数据门控：每个时点必须检查 `sum_b(flow_b)` 近似为零（若是双边净流口径），否则整日废弃。该信号建议首先作为市场 regime/拥挤度，而不是直接解释为机构观点。

## 三、基本面与风格因子

### 6. 四维价值评分（研究笔记 11，第 4-5、11-13 页）

沪深300价值的原文变量为：

```text
BP = latest_book_equity / trailing_1y_average_market_cap
EP = trailing_1y_net_income / trailing_1y_average_market_cap
CFP = trailing_1y_net_cash_flow / trailing_1y_average_market_cap
DP = trailing_1y_cash_dividend / trailing_1y_average_market_cap
z(x) = (x - mean(x)) / std(x)
ValueScore = mean(z(BP), z(EP), z(CFP), z(DP))
```

原文印刷公式的系数为 `1/3` 但右侧有四项；这与“4 个变量 Z 值平均”的文字矛盾，应视为排版/笔误，实施时必须以官方指数方法或明确的等权 `1/4` 复核，不可照抄 `1/3`。原文的处理规则：横截面 5%/95% winsorize，缺失项用同行业均值填补。

研究笔记 11 的月度五分组测试称单因子年化超额约 5%-8%，但这只是历史样本描述。建议在当前 PIT 财务数据上，以公告可得日而非报告期末日期对齐；在股票横截面做行业/市值中性化，并对财务质量低、极端高应计利润股票加限制。

### 7. 价值-质量筛选与低波权重（研究笔记 11，第 5-6、12-13 页）

报告给出的国信价值思路是：先剔除低流动性，再剔除扣非 ROE(TTM)连续下降或质量不达标的公司，最后按 `ROE_ex_nonrecurring / PB` 排序。该思路可作为四维价值的质量门：

```text
quality_value = z(ValueScore) + z(ROE_ex_nonrecurring / PB)
quality_gate = stable_or_improving_ROE and positive_operating_cash_flow
```

不要把静态 ROE 直接作为强 alpha：报告发现其多空表现不稳定；CF/P 与 D/P 更适合承担“质量”部分。若做 Smart Beta 组合，参考报告中的行业中性低波规则，在行业内按历史波动率升序选股、按波动率倒数加权，而不是把低波暴露误当为价值 alpha。

### 8. ESG 分数与争议惩罚（研究笔记 7，第 8-12 页）

报告给出两类模型：负面清单（争议行业/企业剔除）和 E/S/G 综合评分。Thomson Reuters 示例将 178 个指标归为 10 个小项并加权，若负面争议较严重则下调原始总分：

```text
ESG_raw = sum_j(w_j * subscore_j)
ESG_final = ESG_raw,                              if controversy >= 50
ESG_final = ESG_raw,                              if ESG_raw < controversy < 50
ESG_final = (ESG_raw + controversy) / 2,         if controversy < 50 and controversy < ESG_raw
```

这里的 `controversy` 分值和方向须与供应商字段确认；上述仅为报告中汤森路透示例。建议在可获取评级、公告、处罚和新闻事件后，分拆为：`ESG_level`（慢变量）、`controversy_event`（快变量）和 `controversy_decay`（事件后衰减），先做风险排雷/股票池约束，再评估是否有独立 alpha。ESG 不适用于单 ETF 的分钟技术因子；可用于 ETF 持仓穿透后的组合暴露或股票横截面。

## 四、样本池、风险暴露和数据治理

### 9. 指数规则可转化为投资池约束（研究笔记 3，第 4-10 页）

中证规模指数的共同逻辑是“先流动性、后市值”，并使用缓冲区降低调仓冲击。对于股票因子回测，建议采用：

```text
eligible = listed_days > 1_quarter
         & not(ST, suspended, abnormal_price)
         & avg_amount_1y above universe percentile threshold
size_bucket = rank(avg_market_cap_1y)
```

对指数/ETF 策略要记录规模、行业、集中度、换手率和流动性暴露。样本池改变会显著影响 1min 因子的可交易性和容量；因子 IC 必须在大盘/中盘/小盘桶内分别报告。

### 10. 证券主键与点时数据（研究笔记 8，第 1-3 页）

代码变更、吸收合并、重组和退市会造成错误的历史连续性。建议建立 `security_id`（经济实体）与 `listing_id`（交易代码）两层主键：

* 普通退市或重组后新代码：旧 listing 终止，新 listing 视为新股；
* 同一实体代码迁移且供应商追溯历史：只在确认无业务断裂时拼接，并保留原始代码映射与生效日期；
* 回测禁用未来才知道的代码映射、成分股和财务重述。

这一项不是 alpha，但若缺失会污染动量、收益标签、基本面因子及退市收益。

## 统一验证协议

1. **时间对齐**：所有财报、份额、ESG、指数成分使用实际可得时间；1min 标签不跨午休和隔夜。
2. **横截面处理**：winsorize、行业/市值中性化、缺失值显式标记；不得以未来横截面均值填补。
3. **可交易性**：股票剔除停牌、涨跌停及新股窗口；ETF 纳入成交额、价差和容量阈值。
4. **评价**：报告 IC、Rank IC、ICIR、分组单调性、换手、成本后多空/多头收益、最大回撤和不同市场状态表现。
5. **稳健性**：滚动样本、不同股票池、不同延迟、不同成本、不同分组边界；先冻结公式再做全样本扫描，避免数据挖掘。

## 与当前 FractalQuant 的衔接

项目已有 `price_volume_decoupling`、`volume_spike`、`OrderFlowImbalanceFactor`、L2 OFI/MLOFI 与上下文异常片段因子。新增研究应避免重复：

* FLY 是**价格-换手正相关/过热**，应新增为独立因子，不能用现有“价量脱钩”替代；
* 大小单分层流与现有 OFI/MLOFI 互补：前者看成交规模与投资者行为代理，后者看订单簿/队列变化；
* ETF 份额流和价值/ESG 需要单独的日频或跨资产面板生成器，不应塞入仅含单标的 OHLCV 的 `generate_etf_minute_factors.py`；
* 多尺度反转与尾部状态可在现有 1min 技术因子框架中增加，但需要严格日内分组，防止午休与隔夜泄漏。
