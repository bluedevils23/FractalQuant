# APM / OVP 生成口径（版本 2）

入口：`scripts/generate_open_source_apm_ovp.py`。
算法：`FractalQuant/factor/open_source_crossmarket.py`。

## 研报核验

依据开源证券 2020-03-07《APM 因子模型的进阶版》：

- 第 3 页：过去 20 个交易日、两个时段合并为 40 个观测，拟合含截距的 `r = alpha + beta * R + epsilon`；每日残差差计算 `mean(delta)/(std(delta)/sqrt(20))`。原文没有指定标准差自由度，本实现保留样本标准差 `ddof=1`。
- 第 3 页：动量截面回归为 `stat = b * Ret20 + epsilon`，没有截距；输出残差。`Ret20 = adjusted_close[t]/adjusted_close[t-20]-1`。审计字段 R² 为无截距回归的非中心化 R²。
- 第 6 页：APMnew 用隔夜收益替换上午收益，其余步骤不变。
- 第 8 页：OVP/AVP 是逐日分段收益的 20 日算术加总之差，不是复利收益；无需另按成交金额排序。
- 至少 20 个有效标的才计算截面残差，是本项目的质量门槛，不是原文规定。`apm_cross_section_count` 记录 APMnew 实际有效标的数，即使不足门槛也如实记录；APMraw 有独立有效样本。

当前实现是 ETF 跟踪指数适配版本。静态映射表不提供历史生效区间，不能声称历史映射满足 PIT。市值和行业中性化属于研报的回测处理，未包含在这四列因子中。

## 数据与时间

- 输入为收盘时刻标记的分钟线：上午 09:31–11:30，下午 13:01–15:00。
- 开盘优先使用 09:30 集合竞价记录的 open；该记录缺失时使用 09:31 open。下午起点为 13:01 open，不读取 13:00。
- AM/PM 各自要求 120 根具有正、有限 OHLC 的整分钟记录；不完整时对应时段收益为空。
- 隔夜收益及 Ret20 使用原价乘累计复权因子。同日 AM/PM 使用原价；缺失、非正、非有限或日内不一致的复权因子不会破坏日内收益，但跨日字段为空。
- 按 XSHG 交易日补齐缺口，上一收盘只来自上一交易日，不跨缺口沿用。OVP/AVP 不需要指数收益，指数缺口只影响依赖指数的 APM。
- available_time 为下一交易日 09:30，包括最后一天。日历覆盖不足时失败，不用未来行情推算。

## 执行与补跑

默认计算池为映射表全部标的。`--symbols`、`--symbols-file` 和 `--limit` 只控制写出范围；已有文件的标的仍参加本次截面计算。

需要独立的研究计算池时显式指定 `--universe-file`（每行一个带交易所后缀的标的）。更换计算池会改变 APM 定义，应使用不同输出目录。

`--date-from` 前读取 20 个交易日的预热数据，滚动计算和截面回归完成后才裁剪输出。`--date-to` 会限制输入。

示例（在仓库根目录使用 uv）：

```powershell
uv run python scripts/generate_open_source_apm_ovp.py --universe-file fixed_universe.txt --date-from 2026-07-01 --date-to 2026-08-07 --output-root D:\workspace\stockdata\etf-data\apm_v2_research
```

固定池任何成员缺映射、缺文件或计算失败，均返回非零状态，不发布不完整截面的结果。指定交易所的指数只查找同后缀文件；无后缀索引若匹配多个文件则失败。

输出目录使用独占锁和独立临时目录，文件经回读验证后原子替换。`manifest.json` 记录版本、计算池、日期范围、映射摘要及输入文件大小/修改时间；`run_report.json` 记录失败与每个写出标的的有效覆盖。输入在运行期间改变会中止发布。旧文件或不一致的生成来源不能静默跳过；应换新目录，或使用 `--overwrite` 覆盖该目录全部已有标的。

输入来源校验用于运行一致性，不等于历史 PIT 证明。完整历史重算及下游回测需另行执行，旧文件不会自动修复。
